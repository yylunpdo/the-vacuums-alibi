One deadpan excuse a robot vacuum gives for missing a spot, for the make.fun **The Vacuum's Alibi** bounty: the machine does not apologise — it reports, with total sensor confidence, that the corner has seceded from the house and is now foreign soil, outside its jurisdiction.

> That corner is not dirty. My lidar classified it as a sovereign nation, and I do not clean foreign soil.

## Run it

```sh
python3 main.py
```

This writes the single alibi (104 characters, one line, UTF-8, no trailing newline) to `/output/entry.txt` and verifies it meets the bounty rules: 1–200 characters, single line, no leading or trailing whitespace.
